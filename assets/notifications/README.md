# Notification Assets

This folder contains notification sounds for different types of notifications.

## Android

Place these files in `android/app/src/main/res/raw/`:

- `new_order.mp3` - New order notification sound
- `order_status.mp3` - Order status change sound
- `payment.mp3` - Payment received sound
- `general.mp3` - General notification sound

## iOS

Add these files to your Xcode project:

- `new_order.aiff` - New order notification sound
- `order_status.aiff` - Order status change sound
- `payment.aiff` - Payment received sound
- `general.aiff` - General notification sound

Make sure to enable these sound files in your Xcode build phases.
